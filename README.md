# Програмний комплекс для активного сканування та аналізу мережевої інфраструктури локальної мережі

Це локальний desktop-прототип для активного сканування LAN, збереження історії сканувань у SQLite та пояснювального аналізу змін між сканами.

## Можливості

- активне сканування підмережі у CIDR-форматі;
- режими виявлення хостів: ICMP, TCP, mixed;
- налаштовуваний список TCP-портів;
- best-effort hostname, MAC та локальні OUI vendor hints;
- порівняння поточного скану з попереднім сканом тієї ж мережі;
- події змін: новий хост, зниклий хост, відкритий/закритий порт, зміна ролі, невизначене зіставлення;
- attention score на основі мережевих ознак активного сканування;
- Confidence / Decision для пояснення впевненості зіставлення хостів між сканами;
- історія сканувань, паспорт пристрою, TXT/CSV export.

## Запуск

```bash
python main.py
```

Перед запуском встановіть залежності проєкту, зокрема PySide6, якщо вона ще не встановлена у вашому середовищі.

## Attention score

Attention score — це не CVE-оцінка і не повноцінний vulnerability score. Це простий пояснювальний пріоритет уваги оператора на основі evidence з активного мережевого сканування: нові хости, зміни портів, зміни ролі та невизначеність ідентичності.

## Confidence / Decision

Confidence показує числову впевненість алгоритму зіставлення хостів між двома сканами. Decision — технічна категорія результату зіставлення: `auto-link`, `probable-link`, `ambiguous`, `no-link`.

## Export

Через GUI можна експортувати останній аналіз у файли:

- `latest_scan_summary.txt`
- `latest_scan_events.csv`
- `latest_attention_scores.csv`
